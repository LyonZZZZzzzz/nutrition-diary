# v0.4.1-b8

照片食物匹配修复版本。

## 修复

- 修复照片识别名称“流心芝士拿铁（冰，无焦糖）”被错误匹配为“无糖冰咖啡”的问题。
- 食物匹配现在优先使用完整名称和别名包含关系，并对菜名匹配与食材匹配设置不同权重。
- 最佳候选低于 60% 时不再自动选中，避免把低置信度食物直接写入记录。
- 菜品确认页显示最佳匹配依据和匹配度。
- 增加“拿铁必须优先匹配拿铁咖啡而非无糖冰咖啡”的回归测试。

## 验证

- 22 个 Swift 测试全部通过。
- iOS 27 与 macOS 15 构建通过。
- 已安装到 Lyon 的 iPhone 17、iOS 27.0.1，App 正常启动并持续运行。

## 已知边界

- 已经保存的错误营养快照不会自动修改，需要用户删除后重新识别，或在确认页手动选择正确食物。
- 菜品名称本身不在种子库时仍属于近似匹配，用户必须在确认页核对。
