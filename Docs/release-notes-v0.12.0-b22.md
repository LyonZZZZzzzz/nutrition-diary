# v0.12.0-b22

- App version: 0.12.0
- Build: 22
- Created: 2026-10-17

## 用户可见变化

- 食物目录安装体积明显下降，搜索和记录流程保持原有行为。
- 新增冷启动性能基准，后续版本可用同一测试比较启动回归。

## 技术变化

- `Catalog.sqlite` 移除运行时未查询的 `nutrients` 和 `servings` 重复表，仅保留 Payload、FTS5 和元数据。
- Catalog 文件由 93,880,320 字节降至 64,036,864 字节，减少约 31.8%，记录数和中文覆盖率保持 13,498 / 13,498。
- SQLite 文本搜索限制为最多 200 个候选，避免宽泛中文词导致全目录扫描；空查询仍支持有界分页审计。
- `AppModel` 拆分同步、健康和照片职责到独立扩展；主文件从约 830 行降至约 406 行。
- 新增 `make benchmark-catalog` 和 `CatalogPerformanceTests`，并新增 iOS `XCTApplicationLaunchMetric` 冷启动性能测试。
- 增加目录回归门槛和 `Docs/Performance-v0.12.0.md` 性能记录。

## 验证结果

- 共享单元/集成测试、双语资源校验和 Python 目录测试通过。
- iOS UI 测试通过，并新增冷启动性能采样；iPhone 17 模拟器 Debug 平均启动耗时为 3.850 秒。
- iOS 27 与 macOS 15+ 构建通过。
- 真实设备冷启动和真实用户数据库规模仍应在 TestFlight 阶段记录。

## 已知边界

- 性能表的绝对耗时会随模拟器、Mac 和系统负载变化；本轮重点验证包体下降、候选上限和功能不回归。
- 目录精简没有改变历史备份格式或用户饮食记录。
