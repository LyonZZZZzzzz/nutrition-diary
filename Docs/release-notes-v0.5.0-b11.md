# v0.5.0-b11

HealthKit 与 Apple Watch 数据读取优化版本。

## 改进

- 新增活动能量、静息能量和 Apple 锻炼时间读取。
- 改为聚合原始 HealthKit 样本，保留来源名称、产品类型、样本覆盖和最后样本时间。
- 默认优先 Apple Watch；多 Watch 时按覆盖面选择，没有 Watch 数据时回退其他来源。
- 设置页支持自动来源或手动固定来源，手动来源缺少某项指标时不静默回退。
- 今日页新增健康消耗明细：活动、静息、锻炼时间、总消耗、来源和更新时间。
- App 前台注册 HealthKit ObserverQuery，数据变化时短延迟合并刷新。
- App 回到前台时自动刷新当前日期，设置页和今日页保留手动刷新。
- 加强健康状态提示，区分未授权、无数据、部分缺失和读取错误。
- 添加“管理健康权限”入口。

## 验证

- 32 个 Swift 测试全部通过。
- iOS 27 与 macOS 15 构建通过。
- 已安装到 Lyon 的 iPhone 17、iOS 27.0.1。
- 真机设置页正确显示健康状态、自动来源选择和刷新/权限入口。
- 当前尚未完成 HealthKit 读取授权，因此真实 Apple Watch 活动、静息和锻炼时间数值尚未验收。

## 已知边界

- 不启用 HealthKit 后台投递，不在 App 未运行时后台刷新。
- 不读取步数、体重、心率、睡眠或血压。
- 锻炼时间只展示，不参与热量平衡。
- 静息能量仍是 HealthKit 系统估算，App 不提供医学建议。
