# v0.9.0-b18

- App version: 0.9.0
- Build: 18
- Created: 2026-10-17

## 用户可见变化

- 当前离线食物目录实现 13,498 / 13,498 条简体中文名称覆盖，中文模式不再将 USDA 长尾名称作为默认显示。
- 品牌和餐厅原名保留，只翻译菜品、食材、份量和制作方式；例如 `McDonald's Big Mac` 显示为 `McDonald's 巨无霸`。
- 机器生成的中文名称在食物详情页标注“本地机器翻译”，同时展示英文原名供核对。
- 食物数据来源页显示人工审核、台湾参考和本地机器翻译的最终数量。
- 中文搜索支持机器译名、人工中文名、英文原名和英文别名。

## 技术变化

- 新增 `FoodNameLocalizationOrigin` 和 `FoodItem.nameZhOrigin`，区分人工审核、台湾 FDA、本地机器翻译和原始名称。
- 新增可恢复的本地批量翻译工具 `Scripts/translate-food-names.swift`，使用 macOS Translation.framework 英文到简体中文能力。
- 新增版本化翻译缓存 `FoodNameZhTranslations.json`，包含源名称哈希、翻译引擎、记录数及逐条翻译来源。
- 新增品牌保护、重点术语和人工覆盖规则 `Tools/food-name-translation-rules.json`。
- `Catalog.sqlite` 升级为 schema v3，保存中文名称来源；构建时按人工审核、台湾参考、本地机器翻译顺序应用。
- 修复 USDA 导入变量覆盖导致来源标题显示为 `oz`、`cup` 等份量文本的问题。
- 修复覆盖率在去重前统计导致超过总记录数的问题；manifest 新增中文未覆盖数和翻译缓存哈希。
- 全量中文缺失会直接阻止目录构建和发布。

## 验证结果

- 13,498 / 13,498 条目录记录具备非空中文名称，缺失数为 0。
- 中文名称来源：人工审核 122 条、本地机器翻译 13,376 条、台湾参考 0 条。
- 本地翻译缓存覆盖 13,388 个唯一英文名称，通用“食品/菜品”占位回退为 0。
- 本地化完整性校验通过，共 257 个 String Catalog 键。
- 58 项共享单元/集成测试、4 项 Python 目录本地化测试和 5 项 iOS UI 测试通过。
- iPhone 17 模拟器验证食物来源页显示 13,498 / 13,498，并生成覆盖验收截图。
- iPhone 17 真机验证机器翻译食物搜索、详情来源提示、份量、热量、营养记录和今日汇总。
- `devicectl` 确认真机安装版本为 0.9.0、构建号 18。

## 已知边界

- 本地机器翻译属于辅助名称，准确性低于人工审核名称；原始英文名称始终保留供核对。
- 本次不把台湾 FDA 数据作为独立食物记录导入，仅在提供官方参考文件时用于优先覆盖中文名称。
- App 运行时不会调用 Translation.framework，也不会发送食物名称到云端。
