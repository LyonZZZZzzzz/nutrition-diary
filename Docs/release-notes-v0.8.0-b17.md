# v0.8.0-b17

- App version: 0.8.0
- Build: 17
- Created: 2026-10-17

## 用户可见变化

- 添加食物页新增“克数 / 毫升”和“家庭份量”两种录入方式。
- 有家庭份量的食物可直接选择“1个、1碗、1杯、1排”等份量并填写份数，同时显示折算重量或体积。
- 份量变化时实时预览热量、蛋白质、脂肪、碳水化合物、膳食纤维、糖和钠。
- 无效份量显示明确提示并禁用记录按钮；缺失营养继续显示“缺失”，不按零处理。
- 保存成功后才关闭添加页；保存期间按钮禁用并显示进度，避免重复记录。
- 保存后今日页立即更新总摄入、餐次热量和食物条目。
- 今日营养汇总改为覆盖完整营养注册表；顶部完整性提示只依据核心营养，扩展营养逐项保留缺失状态。

## 技术变化

- `AppModel` 新增可复用营养预览接口，并将记录接口改为成功后返回 `DiaryEntry`、失败时抛错。
- 添加食物页复用 `NutritionCalculator` 和 `FoodQuantity`，保证预览值与最终保存值一致。
- 新增 3 项食物记录集成测试，覆盖真实 SQLite 搜索、克/家庭份量计算、SwiftData 保存和完整营养汇总。
- 新增 iOS UI Test Target 和 `make test-ios-ui`；发布归档默认执行 UI 测试。
- 新增 `DeviceTest` XcodeGen 配置，使真机 UI 测试可以绕过占位 iCloud 容器，同时保持 UI Test Runner 无健康权限。
- Debug UI 测试使用 `--ui-testing-in-memory-store`，不读写用户真实 SwiftData，也不请求 HealthKit 或照片分析权限。
