# 1.2.0 (29)

## 用户可见变化

- 新增 120 项可搜索、可记录的中式复合菜：50 道炒菜、15 道炖煮菜、15 道饭面粉饺、10 道汤羹、10 道早餐、10 道凉菜、10 项咖啡奶茶和 10 项甜品。
- 覆盖宫保鸡丁、鱼香肉丝、番茄炒蛋、青椒肉丝、麻婆豆腐等常见菜名，并支持地区别名、常见错写和拼音查询。
- 食物库与餐次添加页显示命中原因，例如“名称精确、别名、拼音、前缀、模糊匹配”，方便判断搜索结果是否可靠。
- 中式复合菜优先按菜品记录搜索，避免“宫保鸡丁”等菜名优先落到生鸡肉或无关英文长尾原料。

## 数据与技术变化

- 新增版本化 `CatalogData/ChinesePreparedDishOverlay.json`，使用稳定 UUID、本地食材配方、可食重量、成品重量和家庭份量生成营养，不直接复制无明确再分发许可的中国食物成分表。
- `SeedFoods.json` 从 110 项扩展到 121 项，补充植物油、酱油、糖、醋、料酒、淀粉、蒜、姜、葱、芝麻油和辣椒酱等调理食材。
- `Catalog.sqlite` 升级到 schema v4，新增拼音、规范组、菜品状态、来源质量、常用度与搜索优先级字段；旧 v3 读取路径保持兼容。
- 目录增至 13,627 条记录，其中 13,627 条具备中文名称；FTS 同时索引中英文名称、别名和拼音。
- 搜索排序统一为当前语言精确名称、别名、拼音、前缀、FTS 和受控模糊匹配，并对规范组去重。
- 新增可复现生成器 `Tools/generate_prepared_dish_overlay.py`，所有复合菜营养按本地食材与成品重量计算，缺失营养保持 `missing`，不会按零补值。

## 验证结果

- `swift test --package-path Packages/NutritionKit`：75 项测试通过。
- 中式复合菜基准包含不少于 200 条名称与拼音查询，top-1 与 top-3 达到方案门槛。
- 已覆盖“鱼香肉丝、番茄炒蛋、宫保鸡丁、地瓜、拿铁”等名称、别名和拼音查询。
- 目录 manifest 校验通过：13,627 / 13,627 中文名称，120 项复合菜，schema v4。
- iOS 与 macOS 构建、UI 测试和归档校验结果以本版本归档 manifest 为准。

## 已知边界

- 本次基准以 120 项人工复合菜的名称和拼音为主，不等同于完整的 200 条独立人工中文长尾查询集；后续仍应继续积累真实用户查询样本。
- 复合菜配方属于估算数据，详情页保留来源和营养完整度，不声称等同于实验室检测值。
- 本次不包含完整中国食物成分表、条码扫描或 Watch 独立 App。
