# v0.5.1-b12

餐次添加页食物搜索修复版本。

## 根因

- 餐次添加页输入框使用局部 `query`，但搜索调用读取的是全局 `model.searchQuery`。
- 添加页从未把输入内容同步到全局状态，因此实际一直使用空字符串或旧查询。
- 食物库页面会主动同步全局查询，所以只有餐次添加页出现无结果问题。

## 修复

- 新增 `AppModel.searchFoods(query:limit:)`，直接接收页面查询并返回结果。
- 餐次添加页和食物库页面分别维护自己的结果与加载状态。
- 查询使用 200ms 防抖，新输入会取消旧任务。
- 增加“正在搜索”和“未找到相关食物”状态。
- 查询为空时恢复完整食物目录。
- 移除共享 `searchQuery/searchResults/updateSearch()` 使用路径，避免页面互相污染。
- 保留现有 FoodCatalog 名称和别名排序规则。

## 验证

- 35 个 Swift 测试全部通过。
- 覆盖“鸡”“地瓜”“拿铁”、空查询、无结果和连续查询。
- iOS 27 与 macOS 15 构建通过。
- 已在 Lyon 的 iPhone 17、iOS 27.0.1 上安装。
- 真机餐次添加页输入“鸡”后正确返回“鸡蛋”和“鸡胸肉”，搜索无结果问题已修复。

## 已知边界

- 输入跨多个领域的字符碎片时，现有目录仍可能返回弱相关结果；本次不调整目录排序算法。
