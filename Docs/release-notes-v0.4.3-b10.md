# v0.4.3-b10

设置页版本信息版本。

## 新增

- 设置页底部新增“关于”分组。
- 显示营销版本、构建号和完整版本，例如 `0.4.3 (10)`。
- 版本信息直接读取 App Bundle，不在界面中硬编码。
- 完整版本支持文本选择复制。
- 新增 Debug 直达设置页启动参数，便于自动化验证。

## 验证

- 26 个 Swift 测试全部通过。
- iOS 27 与 macOS 15 构建通过。
- 已安装到 Lyon 的 iPhone 17、iOS 27.0.1，真机设置页正常打开。
- Bundle 版本为 `0.4.3`、构建号 `10`，与安装包版本一致。

## 已知边界

- 本次不增加远端检查更新功能。
- 不修改图标、启动封面、营养计算或数据模型。
