# v0.4.0-b7

品牌图标与启动封面版本。

## 新增

- 新增简洁几何健康主视觉：深绿背景、奶油白餐盘与叶片、暖橙能量弧线。
- iOS 使用 1024×1024 无文字、无 Alpha App 图标。
- macOS 提供 16 至 1024 像素完整 App 图标集。
- iOS 启动封面显示 App 名称与“记录每一餐，看见营养平衡”口号。
- 新增可复现品牌资产生成脚本和 `Docs/Brand/` 预览资源。

## 验证

- 品牌生成脚本重复运行输出 SHA256 一致。
- iOS 图标无 Alpha，启动封面中文字通过本地 OCR 检查。
- iOS 27 与 macOS 15 构建通过。
- App 图标资源成功编译进 iOS 和 macOS 产品，所有 iOS 图标无 Alpha。
- 已在 Lyon 的 iPhone 17、iOS 27.0.1 上安装并完成冷启动验证。
- 真机启动封面正确显示“饮食营养记录”和“记录每一餐，看见营养平衡”。

## 已知边界

- 本次不制作 App Store 宣传截图或 App 内首页横幅。
- 品牌升级不改变营养、拍照、HealthKit 或数据模型行为。
