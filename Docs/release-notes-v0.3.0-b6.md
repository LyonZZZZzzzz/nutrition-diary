# v0.3.0-b6

食物种子库扩充与复合食物营养计算版本。

## 新增

- 种子库从 30 项扩展到 110 项，并迁移到版本化 `SeedFoods.json`。
- 新增 12 项咖啡与饮品、25 项蔬菜、20 项水果、15 项其他食材和 8 项混合食品。
- 牛奶巧克力内置每 100 克、1 小块、1/4 排和 1 排份量。
- 扩展营养注册表，支持脂肪细分、胆固醇、矿物质、维生素和咖啡因。
- 新增复合食物定义和每 100 克归一化计算器。
- 新增完整复合食物编辑器，可添加食材、填写份量、成品重量和份数。
- 支持直接营养数据和配料配方两种模式，直接数据优先。
- 新增 CSV 食物目录导入、未知列/错误/重复名称预览。
- 食物详情按宏量、脂肪、矿物质、维生素分组展示。

## 验证

- 21 个 Swift 测试通过，覆盖 110 项种子、咖啡、牛奶巧克力、直接数据、配方计算、成品重量、CSV 导入和缺失营养。
- iOS 27 与 macOS 15 构建通过。
- 已在 Lyon 的 iPhone 17、iOS 27.0.1 上安装并打开食物库。
- 真机确认 110 项 JSON 种子正常加载，混合食品和公开来源显示正常，SwiftData 迁移未崩溃。

## 已知边界

- 未内置来源不明的完整中国食物成分表；当前使用公开授权数据组合和 110 项人工种子。
- 复合食物首版只保存在本地，不增加 CloudKit 同步模型。
- 咖啡饮品受配方和奶量影响，数值为公开数据参考，用户可通过复合食物编辑器建立更精确配方。
