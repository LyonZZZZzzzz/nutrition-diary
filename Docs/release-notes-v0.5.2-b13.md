# v0.5.2-b13

健康更新时间显示格式修复版本。

## 改进

- 健康消耗明细右侧不再显示“11 秒”等秒级时间。
- 不足 1 小时时显示“更新于 X 分钟前”。
- 达到 1 小时时显示“更新于 X 小时 Y 分钟前”，始终保留剩余分钟。
- 不足 1 分钟按 0 分钟显示。
- 未来时间或系统时钟偏差不会产生负数。

## 验证

- 新增分钟、小时、剩余分钟、未来时间和“不包含秒”测试。
- iOS 27 与 macOS 15 构建通过。
- 已安装到 Lyon 的 iPhone 17、iOS 27.0.1。
- 真机今日页正确显示“更新于 0 分钟前”，不再出现秒数。

## 已知边界

- 该格式为前端展示计算，不改变 HealthKit 查询或数据更新时间。
