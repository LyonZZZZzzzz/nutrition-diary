# v0.4.2-b9

食物匹配逻辑优化版本。

## 改进

- 照片匹配不再依赖搜索结果顺序，而是对全部食物执行名称和别名评分。
- 增加“冰、热、无糖、少糖、去冰、大杯、小杯”等准备方式修饰词归一化。
- 菜名匹配权重高于可见食材匹配；食材匹配不会轻易覆盖菜名候选。
- 增加中文最长公共子串、长度比例和完整别名包含评分。
- 自动选中候选必须达到 65% 匹配度，并领先第二名至少 7 个百分点。
- 泛化名称如“咖啡”会保留候选但不再自动选中，要求用户确认。
- 确认页在低置信度时显示“未自动匹配，请手动选择”。
- 新增拿铁、冰美式、黑咖啡和泛化咖啡的回归测试。

## 验证

- 26 个 Swift 测试全部通过。
- iOS 27 与 macOS 15 构建通过。
- 已安装到 Lyon 的 iPhone 17、iOS 27.0.1，App 正常启动并持续运行。

## 已知边界

- 菜品完全不在种子库时只能提供近似候选，仍需人工确认或新建复合食物。
- 已保存的错误记录不会自动修改。
